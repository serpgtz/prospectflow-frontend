# prospectflow-frontend

Frontend React + Vite para ProspectFlow.

## Configuracion local

1. Instala dependencias:
```bash
npm install
```

2. Crea variables de entorno locales:
```bash
cp .env.local.example .env.local
```

3. Ejecuta en desarrollo:
```bash
npm run dev
```

## Variables de entorno

- `VITE_API_URL`: URL base del backend.
- Local sugerido: `http://localhost:3000`

## Build

```bash
npm run build
```
